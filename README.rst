=====================
IATI Standard Gazette
=====================

The IATI Standard Gazette is the canonical source of information about changes to the IATI Standard. This repo is the archive of previous proposals and Gazette editions. 

The Gazette can be found at https://standard-gazette.iatistandard.org/en/latest/ and you can subscribe to the mailing list at https://mailchi.mp/iatistandard/iati-standard-gazette 

See https://github.com/IATI/iati-docs-management for tools and documentation about how to build this website and how IATI's documentation is managed.
